Privacy & storage

This is a static GitHub Pages app. Accounts and NVIDIA keys are stored in this browser only; they do not sync between devices. Passwords are salted and hashed locally, but this is not server-side authentication. Your saved NVIDIA key is not encrypted, and requests send it directly from your browser to NVIDIA.

Study-guide text is sent to NVIDIA to create your quiz. If “Find references” is checked, a few extracted topic keywords (not your full guide) are sent to Wikipedia's public API for background context. Avoid shared devices and never enter a key you are not comfortable storing in local browser storage.

For a public app with real accounts and protected API keys, add a trusted backend before deployment.
